# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [семантическому версионированию](https://semver.org/lang/ru/).

## [0.1.0] — 2026-10-26

### Добавлено

- **Анализатор журналов** `scripts/log_analyzer/`:
  - парсеры журнала OpenSSH (syslog) и CSV-выгрузки журнала безопасности
    Windows (события 4624/4625);
  - автоопределение формата по содержимому файла;
  - четыре правила: `brute-force`, `password-spray`, `success-after-failure`,
    `distributed-account-attack`;
  - настраиваемые пороги: число отказов, окно подсчёта, число учётных записей;
  - отчёты в консоль, JSON и CSV, коды возврата для cron и CI;
  - чтение из stdin, поддержка шаблонов файлов, подбор кодировки
    (UTF-8, Windows-1251).
- **Аудит безопасности Windows** `scripts/security_audit/`:
  - 18 проверок: брандмауэр, Defender, SMBv1 и подпись SMB, UAC, гостевая
    запись, пароль автовхода, NLA для RDP, BitLocker, обновления, парольная
    политика, журнал безопасности, Secure Boot, локальные администраторы,
    защита LSA, журналирование PowerShell;
  - оценка защищённости 0–100 с весами по важности;
  - отчёты: консоль, JSON, CSV и автономный HTML;
  - фильтры `-Only`/`-Skip`, `-List`, `-FailOn` с кодами возврата;
  - корректная работа без прав администратора (проверки помечаются
    пропущенными, а не падают).
- **Извлекатель индикаторов** `scripts/ioc_extractor/`:
  - IPv4, IPv6, домены, URL, MD5/SHA1/SHA256, адреса почты;
  - отбрасывание приватных адресов, белый список;
  - дефанг вывода и рефанг входного текста;
  - отчёты: консоль, JSON, CSV.
- **Тесты**: 53 теста Python (`unittest`) и 29 проверок PowerShell без Pester.
- **Документация** на русском: установка, описание каждого инструмента,
  архитектура, безопасность, FAQ.
- **CI** на GitHub Actions: Windows и Ubuntu, Python 3.9/3.12.
- Учебные данные в `samples/`: журнал sshd с атакой, CSV журнала Windows,
  текст отчёта с индикаторами.

### Известные ограничения

- Анализатор поддерживает только два формата журналов.
- Аудит не проверяет процессы, автозапуск и сетевые подключения.
- Дефанг не распознаёт нестандартные способы обфускации.

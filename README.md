# Security Scripts — автоматизация рутинных задач ИБ

Три небольших инструмента для ежедневной работы администратора или аналитика
SOC: поиск брутфорса в журналах, проверка базовых настроек Windows и извлечение
индикаторов компрометации из текстов. Всё написано на Python и PowerShell 7,
без внешних зависимостей, с тестами и документацией на русском.

```
scripts/log_analyzer/analyze_logs.py       — брутфорс и подозрительные входы в журналах
scripts/security_audit/Test-SecurityBaseline.ps1 — 18 проверок настроек Windows
scripts/ioc_extractor/extract_iocs.py      — IP, домены, URL, хеши из текста
```

## Зачем это нужно

Рутина в ИБ хорошо автоматизируется: журналы аутентификации нужно просматривать
каждый день, настройки — проверять после установки и обновлений, индикаторы
компрометации — извлекать из отчётов и писем. Эти скрипты делают такую работу
воспроизводимой: одинаковый результат, машиночитаемые отчёты, коды возврата для
CI и cron, понятные сообщения на русском.

- **Ноль зависимостей.** Только стандартная библиотека Python (3.9+) и
  встроенные модули PowerShell 7. Ничего не нужно устанавливать через pip.
- **Локальная работа.** Скрипты не обращаются к сети и не отправляют данные
  наружу — только читают файлы и настройки системы.
- **Тесты.** 53 теста Python (`unittest`) и 29 проверок PowerShell без Pester.
- **Отчёты.** Консоль для человека, JSON/CSV/HTML для автоматизации и архива.

## Быстрый старт

```powershell
git clone https://github.com/<ваш-логин>/security-scripts.git
cd security-scripts

# 1. Брутфорс в журнале sshd (встроенный учебный пример)
python scripts/log_analyzer/analyze_logs.py samples/auth_sshd.log

# 2. Тот же анализатор для выгрузки журнала безопасности Windows
python scripts/log_analyzer/analyze_logs.py samples/win_security.csv --format win-csv

# 3. Базовые настройки Windows
pwsh scripts/security_audit/Test-SecurityBaseline.ps1

# 4. Индикаторы компрометации из текста отчёта
python scripts/ioc_extractor/extract_iocs.py samples/threat_report.txt --defang
```

## Что внутри

### 1. Анализатор журналов (`scripts/log_analyzer/`)

Разбирает `syslog`-журнал OpenSSH и CSV-выгрузку журнала безопасности Windows
(события 4624/4625), ищет четыре сценария:

| Правило | Что означает | Важность |
|---|---|---|
| `brute-force` | Много отказов во входе с одного адреса | medium → critical |
| `password-spray` | Перебор многих учётных записей с одного адреса | high → critical |
| `success-after-failure` | Успешный вход с адреса, с которого шёл перебор | critical |
| `distributed-account-attack` | Перебор одной учётной записи с 3+ адресов | high |

Отчёты: консоль, JSON, CSV. Код возврата 1 при находках — удобно для cron и CI.
Подробности: [docs/02-АНАЛИЗ-ЛОГОВ.md](docs/02-АНАЛИЗ-ЛОГОВ.md).

### 2. Аудит безопасности Windows (`scripts/security_audit/`)

18 проверок: брандмауэр, Defender, SMBv1 и подпись SMB, UAC, гостевая учётная
запись, пароль автовхода, NLA для RDP, BitLocker, обновления, парольная политика,
журнал безопасности, Secure Boot, локальные администраторы, защита LSA,
журналирование PowerShell. Для каждой находки — команда исправления.

Оценка защищённости 0–100, статусы, код возврата по порогу важности. Отчёты:
консоль, JSON, CSV, автономный HTML. Скрипт ничего не меняет в системе.
Подробности: [docs/03-АУДИТ-БЕЗОПАСНОСТИ.md](docs/03-АУДИТ-БЕЗОПАСНОСТИ.md).

### 3. Извлекатель индикаторов (`scripts/ioc_extractor/`)

Находит IPv4/IPv6, домены, URL, MD5/SHA1/SHA256 и адреса почты. Умеет отбрасывать
приватные адреса, применять белый список и «дефанжить» результат перед
публикацией (`1[.]2[.]3[.]4`, `hxxps://`), а также восстанавливать уже
обфусцированные индикаторы во входном тексте.

Подробности: [docs/04-ИНДИКАТОРЫ.md](docs/04-ИНДИКАТОРЫ.md).

```powershell

```

Оба набора гоняются в CI на Windows и Ubuntu.

## Ограничения

- Анализатор — эвристика, а не SIEM: он ищет характерные шаблоны и не заменяет
  корреляцию событий. Ложные срабатывания возможны, пороги настраиваются.
- Аудит проверяет базовый набор настроек и не является аудитом на соответствие
  стандарту (CIS, ISO 27001). Часть проверок требует прав администратора.
- Извлекатель индикаторов не разбирает PDF, архивы и бинарные файлы.
- Скрипты предназначены для **своих** систем: запускайте их только на тех
  машинах и журналах, на которые у вас есть право доступа.

Подробнее о границах применимости и этике — [docs/06-БЕЗОПАСНОСТЬ.md](docs/06-БЕЗОПАСНОСТЬ.md).

# Тестовые данные

Все файлы синтетические: адреса из диапазонов документации (`192.0.2.0/24`,
`198.51.100.0/24`, `203.0.113.0/24`, `2001:db8::/32`), домены — зарезервированные
`.example` и `.test`. Совпадения с реальной инфраструктурой случайны.

| Файл | Что демонстрирует |
|---|---|
| `auth_sshd.log` | Журнал sshd за 10 минут: распыл паролей с `198.51.100.23`, распределённый перебор `root` с трёх адресов, 18 отказов и последующий успешный вход `admin` с `203.0.113.66` |
| `win_security.csv` | Выгрузка журнала безопасности Windows: серия 4625 по `Administrator`, затем 4624 с того же адреса; строки `SRV01$` и 4672 не должны учитываться |
| `threat_report.txt` | Текст отчёта с индикаторами компрометации для `extract_iocs.py`: IPv4/IPv6, домены, URL, хеши, почта, приватные адреса, шум (GUID, имена файлов, версии) |

## Как воспроизвести

```powershell
python scripts/log_analyzer/analyze_logs.py samples/auth_sshd.log
python scripts/log_analyzer/analyze_logs.py samples/win_security.csv --format win-csv
python scripts/ioc_extractor/extract_iocs.py samples/threat_report.txt --defang
```

Флаг `--exclude-private` на этом образце уберёт почти все адреса: диапазоны
документации (`192.0.2.0/24`, `198.51.100.0/24`, `203.0.113.0/24`) библиотека
`ipaddress` считает непубличными — как и положено.

Ожидаемые находки для `auth_sshd.log`: брутфорс (`203.0.113.66`, high),
распыл паролей (`198.51.100.23`, high), вход после серии отказов
(`203.0.113.66`, critical), распределённый перебор `root` (high).
